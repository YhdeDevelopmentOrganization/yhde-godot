# YHDE for Godot (moved)

YHDE is open source now, and this repository is no longer updated.

- Source code (add-on, native core and server): https://github.com/YhdeDevelopmentOrganization/yhde
- Add-on downloads, signed for updates: https://github.com/YhdeDevelopmentOrganization/yhde/releases
- Website and docs: https://yhde.frostinteractive.fi

The add-on versions here (up to 0.5.0) stay available as they were, under
the licenses they were released with. From 0.6.0 on, the add-on's scripts
are MIT and its native core is GNU AGPL v3; see the new repository.
